### CMI线路和CN2有什么区别

CMI是中国移动国际的承载网，移动宽带用户走它延迟最低。CN2是中国电信的优化承载网，电信用户走它最顺。六六云香港线标的是CMI三网优化，移动直连，电信联通也有优化接入。VMISS香港BGP的做法更细：电信双程CN2、联通AS10099接AS4837、移动CMI，三家各走各的优化线。选哪个先看你家宽带是哪一家。
